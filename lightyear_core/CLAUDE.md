# lightyear_core — Claude guidance

## Purpose
Foundation crate. Provides the `Tick` type, time/timeline machinery, peer identifiers, and shared history-buffer primitive used by every other Lightyear crate. `no_std` by default (requires `extern crate alloc`); `std` only enabled via `test_utils`.

## Key public API
Modules listed in `src/lib.rs:18`. Prelude (`src/lib.rs:42`) re-exports the items below.

- **`tick::Tick`** (`src/tick.rs:10`) — generated by `wrapping_id!(Tick)` macro from `lightyear_utils`; wrapping `u16`. Implements `ToBytes`, `Add`/`Sub`, `Ord`-via-wrapping-diff. `tick::TickDuration(Duration)` is a `Resource` holding the global tick interval. `tick::AtomicTick` (`src/tick.rs:17`) — atomic wrapper with `set_if_lower` (used to track minimum acked tick across threads).
- **`id::PeerId`** (`src/id.rs:38`) — enum: `Entity(u64)`, `Raw(SocketAddr)`, `Netcode(u64)`, `Steam(u64)`, `Local(u64)`, `Server`. `LocalId(PeerId)` and `RemoteId(PeerId)` are `Component` newtypes (`src/id.rs:14, 26`).
- **`timeline`** (`src/timeline.rs`) — `Timeline<T: TimelineConfig>` (`:23`), `TimelineConfig` trait (`:33`), `NetworkTimeline` trait (`:42`) with `now()`, `tick()`, `overstep()`, `apply_delta()`. `LocalTimeline` is the default per-app timeline. `Rollback`, `SyncEvent`, `is_in_rollback`, `NetworkTimelinePlugin` re-exported in prelude. `TimelinePlugin` is owned by `CorePlugins`.
- **`time`** (`src/time.rs`, 859 lines) — `TickInstant`, `TickDelta`, `Overstep`. The hot path for tick math; uses the `fixed` crate for sub-tick fractions. Where to look when debugging time drift between client/server.
- **`history_buffer::HistoryBuffer<R>`** (`src/history_buffer.rs:14`) — `VecDeque`-backed history of `HistoryState<R>` (`Removed | Updated(R)`) keyed by `Tick`. Used by prediction/interpolation crates to roll values back/forward.
- **`interpolation::Interpolated`** (`src/interpolation.rs`) — marker `Component` for entities that get interpolated.
- **`prediction::Predicted`** (`src/prediction.rs`) — marker `Component` for client-predicted entities.
- **`network`** (`src/network.rs`, 3 lines — placeholder/stub).
- **`plugin::CorePlugins`** (`src/plugin.rs:6`) — `tick_duration: Duration`. Adds `bevy_time::TimePlugin` (if missing) and `TimelinePlugin`. Installed by `lightyear`'s `SharedPlugins`.

## Feature flags
- `default = []`. Truly minimal.
- `test_utils` — pulls `mock_instant` for time-mocking in tests; turns off `no_std`.
- `not_mock` — escape hatch so `cargo doc` / `cargo clippy` don't trip the `mock_instant` swap.

## Notable internals
- `Tick` arithmetic uses `wrapping_diff` from `lightyear_utils::wrapping_id`; ordering is wrap-aware so a tick close to `u16::MAX` correctly compares as "before" tick `0`.
- `AtomicTick::set_if_lower` (`src/tick.rs:35`) is a CAS loop comparing via `wrapping_diff`, used to coordinate the lowest pending tick across systems.
- `NetworkTimeline::PAUSED_DURING_ROLLBACK` (default `true`) controls whether a custom timeline advances during rollback frames.
